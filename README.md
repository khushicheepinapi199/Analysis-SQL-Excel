# Financial Transaction Analysis using SQL and Excel

A beginner-friendly portfolio project demonstrating SQL querying, Excel analysis, data cleaning, and basic financial transaction review using **synthetic data**.

## Skills Demonstrated
- SQL: `SELECT`, `WHERE`, `JOIN`, `GROUP BY`, `CASE`, CTEs, aggregation, and window functions
- Excel: formulas, summary metrics, conditional formatting, charts, filtering, and dashboard-style reporting
- Data analysis: transaction trends, customer-level summaries, cross-border activity, and high-value transaction review

## Project Structure
```text
data/       Synthetic customer and transaction CSV files
sql/        SQL analysis queries
excel/      Excel workbook with analysis and dashboard
reports/    Short analysis summary
```

## Questions Explored
1. Which transactions exceed a high-value review threshold?
2. Which customers have the highest total completed transaction value?
3. How much activity is cross-border?
4. How do transaction values change by month?
5. Which records should receive higher review priority based on simple rule-based indicators?

## Important
All names and transaction records in this repository are synthetic and created only for learning and portfolio demonstration.
